# Project Documentation

This folder contains selected documentation from the Canada Vapes data analytics capstone.

The documentation demonstrates the project's planning, data preparation, ethics and governance considerations, quality-assurance process, and project progress.

## Documents

### Project Plan
Defines the project scope, objectives, roles, deliverables, timeline, and analytical approach.

### Data Preparation & Ethics
Documents data preparation decisions, ethical considerations, privacy, governance, and responsible use of analytics.

### Blockers & Solutions
Documents project challenges and the approaches used to address them.

### Milestone Status
Provides evidence of project progress and development throughout the capstone.

## Privacy Note

Documents published in this public portfolio must be reviewed for confidential client information and unnecessary personal information before publication.
