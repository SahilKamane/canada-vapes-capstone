# Power BI Dashboard

This folder contains portfolio-safe previews and selected visualizations from the Canada Vapes capstone Power BI dashboard.

## Dashboard Focus

- Regional AOV versus the $120 target
- Historical and three-year AOV forecast
- Addressable next-order gap
- Regional priority scores
- Regional reach versus AOV-growth difficulty
- Active customer mix

## Privacy Note

The original Power BI `.pbix` file and underlying client dataset are not included in the public repository because they contain proprietary project data.

Dashboard previews are provided for portfolio and educational purposes.
